## 跨仓边界

- 本目录只维护 **Web / 服务端**。Android 的构建、发布、服务器设置与阅读器文档以 [CustodySim-app](https://github.com/PDSB001/CustodySim-app/blob/main/docs/README.md) 为准；本仓只保留[入口](android-development.md)、[原生协议](android-client.md)与[构建缓存索引](android-build-cache.md)。
- 原生客户端的接口契约变化必须同时更新[原生客户端接入规格](android-client.md)与 App 仓库说明；只改一侧会让旧 App 静默降级。

## 文档维护规则

1. 改功能时同步对应指南；改环境变量时同步 `.env.example` 与[配置参考](configuration.md)；改原生协议时同步双仓说明。
2. 当前指南页首写核对日期；历史记录保留原日期与原测试结果，不把旧数字改写成新结论。
3. 新增审查放 `reviews/YYYY-MM-DD/`，并区分原始报告、复验、修复与剩余事项；单次生产排查可放 `reviews/YYYY-MM-DD-<主题>.md`。
4. 示例统一用 `example.com` 与占位标识，不写真实凭据、会话、业务截图或私有网络配置。
5. 图示须有可读文字与替代描述，并说明是结构示意还是实际截图；可公开配图放 `assets/`，真实设备与诊断截图留在忽略的 `artifacts/`。
6. 链接用仓库相对路径或另一仓库的公开链接，不依赖某台机器的绝对目录；链接改路径时在同一提交里更新引用。
