## 当前阶段

当前已扩展到顶部栏与底部导航栏。我的 → 视觉效果提供 Miuix SwitchPreference 和
OverlaySpinnerPreference，已有安装默认 OFF，开启后默认 GLASS；关闭再开启保留用户上次选择。
顶部栏保留 Miuix 的收拢标题与操作区，使用无折射的 12dp 背景模糊；列表增加顶部内容内边距并允许滚动到标题下方。OverlaySheet 半透明试点已因文字透底重影撤回，最终保留 Miuix 原生实色背景；真实模糊须先解决内部位移动画的坐标同步，不在外层强套材质。SettingGroup 和聊天气泡尚未接入。

## 绘制方式

Modifier.blur / RenderEffect 模糊的是它们所属的图层，不能直接获取兄弟组件背后的像素。
现使用 AndroidLiquidGlass / Backdrop 2.0.1 的 layerBackdrop / drawBackdrop，底栏只处理自己覆盖区域及模糊边缘所需的范围，
在该小图层上应用 12dp 模糊、10dp 边缘折射（18dp 强度）以及库提供的方向高光，最后绘制清晰的 Miuix NavigationBar/NavigationBarItem。折射由库在 API 33+ 启用；API 31/32 只模糊。
未使用截图 Bitmap、CPU 读回、逐列表项模糊或整页 alpha 合成。

页面来源必须排除导航栏及弹层宿主，避免捕获自身产生循环。底栏开启时，列表可以滚动到
它背后，contentPadding 保证末项仍能完整滚出底栏；关闭时恢复原有视口。
利用 Scaffold 先绘制页面、再绘制导航栏的顺序更新来源，背景捕获交给库的 Modifier.Node 管理。
首轮实测发现即便关闭读取观察，来源修订号仍会通过兄弟节点使父图层持续重绘，已移除。

参考：[Compose 图形图层](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)
及 [RenderEffect](https://developer.android.com/reference/android/graphics/RenderEffect)。
模糊的实际 GPU pass 数取决于系统实现，不能将一次 API 调用等同于一次 GPU 采样。

## 降级和预算

- API < 31、非硬件加速或 low-RAM 设备：GLASS → SOFT。
- 系统省电或动画时长/过渡动画缩放为 0：在能力限制后的档位下降一次；两条件同时满足不叠加下降。
- 按最新反馈移除滚动降级，滚动期间保留玻璃效果；列表缓存窗口不变。
- 最多两个材质实例取得模糊名额，超额实例只使用柔和材质；实例退出时释放名额。
- 单层面积超过页面来源视口的 35% 时使用柔和材质，禁止全屏模糊。
- OFF/SOFT 或没有材质实例时，不记录页面显示列表。主题动画值在 draw 阶段读取。
- 系统策略不覆盖持久化偏好，恢复正常后使用用户选择的档位。

## 第二轮材质调整

用户反馈图标偏上、滚动降级破坏效果。保留原生 Miuix 导航和六个文字标签，玻璃模式下条目向下做 3dp 光学对齐。玻璃来源升级为 https://github.com/Kyant0/AndroidLiquidGlass 的 Backdrop 2.0.1；不使用其自定义 Tab 示例替换 Miuix。新材质静止/滚动性能需单独验证，之前测试数值不代表新版。

接入库后首次实测发现来源与底栏共用父显示列表会触发循环重绘。已在 layerBackdrop 前增加独立 graphicsLayer 隔离来源；这不是整页离屏 alpha 合成，底栏仍只处理小面积。需要以修复后静止帧计数再次确认。

隔离后优化包已安装。gfxinfo 两次采集 uptime 60481936 / 60504216，相隔 22.28 秒总帧数均为 403，静止循环重绘已消除。最终画面 effects-liquid-fixed.png。滚动时的 OFF/GLASS 对照仍待固定操作测量，不能将启动混合样本作为性能提升依据。

## 顶部与弹层扩展

- 主页面上下两处玻璃共享页面来源，仍限制最多两层。
- 顶部是直边区域，关闭镜片折射，避免对零圆角运行边缘折射。
- 长表单、通知弹层不模糊全屏，也不更改 Miuix 的拖动和关闭动画。
- 聊天会话保留原有内容视口和键盘避让，顶部背景可使用材质，但不改变消息区布局。

双层材质首轮真机验证：主列表滚动后顶部出现背景柔化，标题与末项均可见。uptime 70769416 / 70785095（15.679 秒）帧数同为 3537，无静止持续重绘。根据截图移除直边顶部的四周高光，将顶部底色 alpha 调为浅色 0.65、深色 0.75，提高文字辨识度；底栏参数不变。

档案弹层截图 effects-sheet.png 显示：即便 alpha 0.96，背后文字仍形成可辨识重影，故否决无模糊半透明方案并恢复实色背景。真实玻璃当前只用于顶部和底栏。档案电子签名显示‘图片无法预览’，本轮未修改图片请求逻辑，也未尝试提交或生成数据。

## 材质命名与折射修正

用户指出旧效果是柔和磨砂。本轮将 12dp 背景模糊正式归入 SOFT；GLASS 底栏改为 AndroidLiquidGlass Backdrop 2.0.1 的 4dp 模糊 + 16dp 折射边缘/32dp 位移 + depthEffect + 方向高光及轻内外阴影，底色 alpha 浅色 0.20 / 深色 0.30。参考官方 https://kyant.gitbook.io/backdrop/tutorials/glass-bottom-bar 和 LiquidBottomTabs 示例；继续使用 Miuix 导航，未复制示例控件。直边顶部明确保持柔和，不标称折射玻璃。API 31/32 仅柔和模糊，API 33+ 才启用镜片折射；省电/减弱动画及不支持设备不采样模糊。

新镜片参数优化包已安装，6 项 EffectsPolicyTest 通过。真机 effects-refraction.png 可见底栏后方蓝色开关在边缘发生拉伸折射；导航前景未被折射。较低遮盖度使背景更明显，仍需用户评估长时间使用时的可读性。

用户确认停止操作后的两次采样：uptime 71322406 / 71349148，间隔 26.742 秒，总帧数均为 4991，未观察到静止持续重绘；崩溃日志为空。之前增长的混合计数包含用户对比操作，未据此判断循环重绘。

## 顶栏与页面底色一致性

采样背景从 colorScheme.background（卡片底色）改为 colorScheme.surface（Scaffold 实际页面底色），同时直边顶部不再运行 vibrancy。修复浅色顶栏发白、深色顶栏偏亮的根源；仍保留实际内容滚动到顶栏后方时的柔和模糊。底栏的镜片折射与高光不变。

## 玻璃底栏选中态

增加装饰性 GlassTabIndicator：仅 GLASS 档启用，按 Miuix 六等分导航槽对齐，圆角浅底 + 细高光 + 6dp 硬件阴影，位于原生 Tab 前景之后。索引切换使用阻尼弹簧移动同一底片，位移状态在布局阶段读取；不接管点击、无障碍语义，不增加背景模糊采样层。
