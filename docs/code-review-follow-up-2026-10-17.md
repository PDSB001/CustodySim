## 验证和部署

独立复验的补充修复：错误页使用项目 Button、共享标题及独立 CSS，覆盖键盘焦点与全局布局缺失时的暗色回退。新增生产构建浏览器测试和 CI 入口，检查普通页面、地图动态脚本、eval 和 Blob Worker 的 CSP 违规事件；SDK 采用受控响应，服务及数据库均为本地隔离环境。

生产 CSP 回归还暴露了 Zod 浏览器 JIT 探测触发 eval 违规，浏览器入口已关闭该探测，普通页面继续禁止 unsafe-eval；地图页面保留 SDK 所需的独立权限。

修复代码提交为 `bb55d1b`。验证结果：388 项单测、96 项业务数据库与 15 项评分数据库测试通过；主浏览器回归 66 项通过、8 项按配置跳过，评分安全浏览器回归 10 项通过，生产 CSP 浏览器回归 2 项通过。运维安全测试、lint、typecheck、Turbopack 生产构建均通过。

数据库回归仅使用 custodysim_e2e；没有执行生产部署、生产数据写入或结构迁移。成功 API 响应和阅读/打卡协议兼容，独立 Android 仓库本批未修改。

部署继续使用 git pull --ff-only 后执行 bash scripts/deploy.sh；无需新增 env 或升级数据库。MFA 运维重置的新确认参数按脚本提示提供。
