# 匿名社区

Web：管理端 /community，监管员 /supervisor/community，被监管人 /my/community。Android：首页右上角消息图标和“我的 → 匿名社区”。所有已登录且未被停用、无需首次改密的用户可使用同一个社区。

支持发布文字和最多 3 张 JPEG/PNG/WebP 图片，每张压缩后不超过 1MB；支持分页评论、本人删帖/删评论，管理员可以删除任何帖子和评论。删帖会同时删除评论与图片。图片通过有鉴权的独立端点返回，帖子列表不携带 base64。

Android 社区使用独立全屏 Miuix 页面：首页入口打开大标题列表，发帖和详情使用小顶栏；不会再覆盖在首页的底部弹层中。列表有图片缩略图、发布时间和评论数。发布页把标题和正文放在一块编辑区，顶栏提交，图片以最多三格排列；处理图片时不能提前发布。上传进度与等待服务端发布的状态分别显示。草稿使用现有加密 DraftStore，按服务器和账号隔离，返回或重启后可恢复，发布成功后清除。

详情底部固定匿名评论输入，适配键盘；评论按时间顺序分页，发送成功后定位到刚发布的评论。图片支持全屏翻页、双击与双指缩放，放大时拖动图片，恢复原尺寸后可以翻页。列表、编辑器和详情保留独立滚动状态；页面连同顶栏、评论输入一起过渡，退出动画保留原内容。界面沿用应用的 Miuix 深浅主题与减少动态效果设置。

列表和评论支持增删渐显及位置过渡，刷新进度占用固定高度，避免推挤现有内容。发布和评论按钮在固定空间内切换文字/图标与加载圈，保持居中；图片选择支持增删、补位及解码渐显，图片预览保留退出内容并平滑缩放。减少动态效果开启时，这些过渡立即完成。普通返回保留全部已加载分页，刷新会重新读取这些分页后一次更新；成功写入后同步评论数量，并保护较早开始的列表请求，避免覆盖已确认的操作。若立即返回取消了详情读取，列表会重新同步。删除评论导致页码越界时退到有效页，手动翻页会取消新评论的自动定位。

社区 API 不返回作者的 userId、用户名、姓名、头像、角色、组织或源档案 ID。楼主在同帖评论标为“楼主”，其他参与者使用按帖计算的 HMAC 匿名编号；不同帖的编号不同。服务端保留作者 ID 用于权限校验。身份隐藏仅指系统作者信息，用户主动写在正文/图片中的信息不会自动识别删除。

档案填写默认不分享。用户可以勾选自愿分享，逐项选择已填写的字段并预览。表单内所有文字、数字、选择、日期及抄写字段均可选，包括姓名、证件号、联系方式等身份字段和自定义字段；未勾选的字段不会公开。照片、签名、公章和 IMAGE 字段不参与档案分享，账号等系统元数据也不会自动加入。服务端从已保存档案重新提取所选字段，不能直接提交任意公开快照，也不能选择表单之外的字段。保存草稿仅保存选择；提交会签成功时与档案事务一起发布快照，后续档案改动不会静默公开。重新提交会更新原分享帖；重新提交时取消分享会移除原分享帖。本人可在社区删除分享帖。

Web、Android 和服务端按字段类型采用相同规则，不再限制为固定的 8 或 30 个字段，也不再限制最多只能选 8 或 30 项。新增可选字段保持未勾选，原有选择不会自动扩大；籍贯、出生年月/日、罪名、刑期日期、纹身/疤痕等体征备注均由用户自行决定是否分享。作者身份展示仍为匿名编号，但用户主动选择公开的身份字段会原样出现在正文快照中。

Web 和 Android 分享选项按分类默认收起，体貌和身体尺寸合并为“体态特征”一个入口。整组选取仅包含本类当前已填写的内容，可展开调整单个字段；后续填写的内容不会自动加入已选范围。Android 使用 Miuix ArrowPreference 作为分类入口，展开后通过 CheckboxPreference 选择整类或单个字段，分类行不再同时放置箭头和开关，间距和点击反馈沿用库默认值。说明独占一行，公开预览使用独立卡片并按分类汇总。清空已选字段的值时同步取消该字段的分享选择。

## 数据库升级

已有数据库先执行：node scripts/upgrade-community.mjs --database=<目标数据库名>。脚本核对实际数据库名后，在事务里增建三张社区表、两个档案字段和索引；可重复运行。不要对生产数据库使用 drizzle-kit push 自动确认。

新数据库使用项目现有 schema 初始化流程。本机 custodysim 和独立测试库 custodysim_e2e 已完成升级；部署到其他环境前仍需对目标库执行此脚本。未发布服务端或安装 App。

## API

- GET /api/community/posts?page=0：每页 20 帖，posts / hasMore
- POST /api/community/posts：title / content / images（data URL 数组）
- GET /api/community/posts/:id?page=0：post / comments / hasMore，每页 30 评论
- DELETE /api/community/posts/:id
- POST /api/community/posts/:id/comments：content
- DELETE /api/community/comments/:id
- GET /api/community/images/:id：图片字节，仅登录后可访问
- /api/profile-records 保存草稿增加 communityShare / communityShareFields；旧客户端缺省不分享
