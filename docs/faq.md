# 常见问题

本页先给使用者可执行的检查；需要服务器处理的事项交给技术维护人员，不要求普通用户运行命令。

## 登录与账号

**为什么 App 提示要改初始密码，却没有修改入口？**

当前 App 没有改密页面。请先用浏览器打开同一系统，在 Web 完成初始改密，再用新密码登录 App。

**密码正确，为什么还需要一个代码？**

账号启用了双重验证。使用验证器当前代码或已保存的恢复码；检查手机时间是否自动同步。不要把验证码、恢复码发给其他人。遗失验证器且没有恢复码时联系管理员，安全邮箱不能直接代替验证器。

**为什么提示稍后再试？**

连续尝试可能触发登录限流。等待页面显示的时间后再核对账号密码；反复点击不会缩短等待。

## 提交、审批与打卡

**点了保存，为什么管理人员说没收到？**

先看是否只是保存草稿。任务要提交，档案要「提交会签」，申请要提交后出现在列表中。草稿不等于已送审。

**网络断了，不知道刚才提交是否成功，要重发吗？**

恢复网络后先刷新对应记录，看状态、内容和时间。确认没有成功记录后再操作；仍不确定时把发生时间和记录交给管理人员核对，避免重复提交。

**打卡按钮怎么没有了，或者还不能点？**

检查是否尚未开始、已经结束、已完成或免打卡。App 只突出第一顺位待打卡，其余过期/已完成记录在下面；错过时有补卡入口才可申请。页面安排不符时联系管理员核对规则。

**申请通过了一级，能按自己填的时间执行吗？**

不能据此判断最终获批。请假与临时离监须核对最终批复和核准时间；有疑问向审核人员确认。

## 定位与通知

**打开了打卡 GPS，为什么后台没有位置上传？**

这是两个独立开关。打卡 GPS 位于「点名」，后台上传位于「我的 → 位置上报」。分别检查开关、系统定位服务和所需权限。

**选了 5 分钟，为什么没有每隔 5 分钟准时上传？**

该周期用于尝试采集，省电、休眠、网络和厂商限制可能延后。5/10 分钟档使用常驻服务通知；检查 App 是否被强制停止、后台权限是否允许，以及首页是否还有等待上传的数据。

**没有手机通知，是不是没有新消息或上传失败？**

不一定。系统内通知、聊天实时消息和 Android 通知权限是不同机制。先在 App 查看状态，再检查系统通知权限。当前没有完整的厂商离线消息推送，应用关闭时不能保证收到聊天提醒。

## 聊天、图片与档案

**为什么只能看到部分聊天对象？**

会话由账号身份、所在监室、授权和私聊审批决定。跨监室私聊先查看「私聊申请」状态；不应通过切换账号绕过限制。

**图片能不写文字直接发送吗？**

可以。选择图片后说明可留空；同时写说明时应在同一图片消息中显示。仍要求文字或发送失败时，记录 App 版本和提示，由维护人员检查客户端与服务端是否同时更新。

**消息为什么没有立即出现？**

先检查网络并刷新会话。多人同时只能刷新后看到消息时，向维护人员反馈发生时间；维护人员应按[部署排障](deployment.md)检查实时服务和反向代理。

**生成了档案图片，为什么档案还是草稿？**

导出只生成副本，不改变审批状态。需要送审时回到填写页核对内容，再「提交会签」。最终公章也不会因导出自动产生。

**导出的图片在哪里？**

Android 在显示保存成功后，通常可从系统相册或「图片/CustodySim」查找。仅看到预览不一定已经保存；如果显示失败，保留提示并重试。Web 的文件位置取决于浏览器下载设置。

**更换头像后另一端没变？**

裁剪确认后还要保存账号头像。保存成功后刷新另一端；仍未同步再向维护人员反馈，不必反复上传。

## 如何提供有效反馈

可以按下列格式发给管理或维护人员：

```text
使用端：Web / Android；App 版本：
发生时间：
所在页面和操作：
期望结果：
实际提示或表现：
是否每次出现、是否其他人也遇到：
相关记录标识（如有）：
```

截图遮挡无关姓名、头像、聊天和定位信息。不要附密码、验证码、恢复码、登录令牌或服务器密钥。
