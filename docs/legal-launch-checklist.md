# 协议和账号权利上线准备

当前 `/terms` 和 `/privacy` 为正式版本 `2026-11-01-v1.0`，生效日期为 2026-11-01，统一使用“服务提供者”称呼实际运营者，并说明经组织管理员转交的联络渠道。部署者仍须履行适用的身份及联系方式告知，核对实际启用的第三方、处理地域、保存期限和跨境安排，并维护有效权利请求渠道。正式文本不代表具体部署已通过法律审核，也不替代敏感信息或跨境处理依法需要的单独同意。

自主注册时服务端要求当前协议和隐私政策版本，注册事务将版本及时间写入 `REGISTER` 审计记录；当前审计记录清理策略为 730 天，不能当作永久同意凭证。现有账号、管理员创建账号和 App 登录没有补签或协议更新确认流程，不应声称它们已同意。文本或处理规则变更时，更新 `lib/legal-version.ts`，通过发布记录保留旧文本，并为已有用户实施告知和依法需要的确认；当前没有面向用户的历史文本归档页面。

权利请求由实际服务提供者接收，核验身份后检查账号及关联数据，记录请求和处理结果，并在适用期限内答复。管理员删除接口可能因业务历史关联而拒绝删除；停用不等于删除。核对个人资料、社区、聊天、附件、日志、第三方及备份，明确合法保留依据与期限，再选择删除、匿名化或其他依法适用的处理方式。当前没有自助申请、处理队列、全量导出或自动级联删除实现，不应向用户承诺已具备这些能力。
