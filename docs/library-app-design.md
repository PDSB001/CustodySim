# Android 图书馆与阅读器

沿用应用现有 MiuiX 蓝色主题。图书馆是独立全屏工作区，首页入口和应用顶栏入口始终可用。本次重做用封面书架替代设置列表式图书卡。

## 书架

- 首屏仅一行服务端确认的今日阅读分钟数与实际积分，不占据正文式大卡。
- 最近阅读以紧凑横卡显示真实封面、书名、上次页码。手机两列、平板三列封面网格展示书架。
- 学习任务直接展示实际完成时长与自动通过状态，随后是书名／作者搜索和格式筛选。
- 封面通过现有认证图片加载器获取，缺失封面明确显示暂无封面，网络失败显示封面暂不可用，不生成假图片。加载、空书架、无搜索结果和服务端错误分别处理。

## 原生管理员工作区

管理员可直接在应用图书馆进入管理，包含图书、阅读任务、积分三个页签。图书支持系统文件选择器上传电子书及可选封面、书名作者编辑、文件和封面替换、封面移除、上下架，以及二次确认后移出书架。未上架图书在管理员列表保留且不能打开阅读；移出采用服务端软移除，历史阅读记录保留。电子书最大 20 MiB，封面 PNG／JPEG／WebP 最大 3 MiB，客户端读取时执行上限检查，上传继续使用已有认证 HTTP 客户端。

阅读任务支持新增每日任务、设置阅读分钟数、派发时间、完成时限，并选择全体、个人或任务组。已有任务支持编辑和启停；只在用户修改时间时替换原时段，保留原频率和范围。积分页可启停并配置每分所需分钟数与每日上限（最多 3 分）。所有操作以服务端成功响应为准，失败保留编辑内容可重试。

## 阅读器

正文占据主要空间。顶部保留退出、书名、外观入口，底部保留上一页、页码跳转和下一页；计时仅占底部一行小字，显示服务端已确认的本次阅读分钟数与暂停／重连操作。

TXT、EPUB 和 DOCX 使用后台提取的文本，每页 2,000 个 Unicode 码点，与 Web 保持一致。正文可选中，采用 19sp 字号与 1.85 倍行距，支持 16–28sp、三档行距，以及暖纸、浅色、深色阅读背景。偏好保存在应用私有 SharedPreferences，重开继续使用。

PDF 保留原页面。提供双指平移缩放和按钮缩放（100%–300%），复位入口与页码跳转，页面图像渲染像素数有上限。PDF 页面自身的颜色保持原样；暖纸／深色用于阅读器周围区域。

页码导航和阅读控制保留系统安全区，书名超长时省略而不挤占控制按钮。外观设置与页码输入展开时暂停计时，关闭后恢复；字号改变不改变文本分页与跨端进度。

## 计时与状态

计时会话仅在生命周期 `RESUMED` 时运行，心跳串行提交，每 15 秒一次；页码和暂停状态变化会及时提交。进入后台和退出时在 `NonCancellable` 清理阶段关闭会话。网络错误或会话失效时停止正常计时提示，提供重连，不按本地秒数推算积分。

积分和任务结果以服务端 ACK／重新获取的图书馆数据为准。自动通过仅在服务端确认后显示轻量提示；返回书架时重新读取进度与今日摘要。电子书下载使用现有带认证的 ApiClient，PDF 临时文件存放应用私有缓存并在关闭时删除。

主代理已确认 Kotlin 编译与 Android 单元测试通过。尚未在实际设备上确认双指操作、系统大字体以及各种屏幕尺寸下的视觉结果。
