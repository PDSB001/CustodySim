# Web 图书馆与阅读器

## 书架

沿用现有紫色品牌和按钮。书架采用 2:3 真实封面，桌面展示最多五列，手机保持两列；封面下方显示书名、作者、上次位置和阅读入口。最近阅读横卡带封面，再展示今日阅读与当前学习任务进度。支持书名/作者搜索以及 EPUB、PDF、DOCX、TXT 筛选。缺少封面时使用中性占位；封面来自管理员上传或 EPUB 原书提取，不制造书籍内容。

今日分钟、积分、学习任务状态均来自服务端。书架返回时刷新；阅读计时不会在浏览器中推算积分。新学习任务的分钟要求由后台配置，达到要求后后台自动通过。

## 阅读

默认使用暖纸背景、20px 中文衬线正文和 2 倍行距，正文行长限制在 780px 容器内。TXT、EPUB 和 DOCX 可选择文字，按既有每 2000 个 Unicode 字符分页规则保留跨端页码。提供 16–28px 字号、1.6–2.4 行距与暖纸/明亮/夜间三种背景，设置保存在本设备 localStorage。

PDF 保持原排版，75%–200% 缩放同时改变实际渲染分辨率和显示宽度。放大后允许横向滚动，换页重置水平位置并保留缩放比例。所有格式都有页码输入跳转、前后翻页和方向键操作。

顶栏只保留返回、书名、细小累计时长、暂停、设置与专注入口。专注模式遮住外部页面，保留退出按钮与 Esc，限制键盘焦点在阅读器内并禁用背景交互。底部显示翻页与服务端确认后的同步状态；积分/任务完成通过安静的文本反馈，不打断正文。

计时保留 15 秒串行心跳、前台窗口可见且有焦点条件、暂停/恢复以及退出关闭会话。打开阅读设置时临时暂停，立即通过同一队列发送状态心跳；关闭设置后恢复用户此前的暂停状态。时长仅累计服务端确认值；保存异常停止计时并给出明确恢复入口。

## 管理

管理员在任何图书馆入口都通过服务端角色进入管理工作区，提供图书管理、阅读任务、阅读积分三个明确标签页。

图书管理显示真实封面、书名作者与上架状态，支持上传、编辑资料、更换正文、更换或移除封面、上架/下架和确认后软移出书架。上传说明电子书最大 20 MB，PNG/JPEG/WebP 封面最大 3 MB。编辑及上传使用本页可滚动弹窗，窄屏完整可用。软移出保留已有阅读记录。

阅读任务可在本页创建每日学习任务，填写分钟要求、开始时间、完成窗口和任务对象（全体、指定用户或已有任务组），查看要求并编辑/启停。编辑已有非每日或多时段规则时保留其频率和时段，避免意外改变排程。修改影响后续生成任务，已生成任务的快照保持原要求。积分标签页直接编辑现有积分策略。

## 验证边界

原阅读器已通过 TypeScript、ESLint、生产构建及 243 项单元测试。主代理使用隔离示例数据，在 390×844 和 1280×850 浏览器视口检查了继续阅读、筛选、主题字号、专注模式与 Esc、跳页、PDF 渲染与缩放及计时暂停恢复。新增封面与管理标签页目前通过定向 TypeScript 和 ESLint，浏览器复核由主代理接续。预览不写入真实数据库或积分。

真实数据库自动结算及真实文件导入需要已迁移并登录的环境。DOCX/EPUB 阅读采用导入正文，不保留复杂图片版式；PDF 当前为画布渲染，原 PDF 正文没有浏览器文字选中层。
