# 安全邮箱与腾讯云 SES

安全邮箱用于绑定确认、换绑通知及 MFA 启用/关闭通知。所有角色仍使用 TOTP 或离线恢复码完成登录 MFA；邮箱不会自动重置密码、替换验证器或关闭 MFA。遗失验证器且没有恢复码时应联系管理员，不能仅凭新邮箱验证码恢复访问。

## 腾讯云配置

使用腾讯云官方 SES API SDK，固定访问 `ses.tencentcloudapi.com`，不使用 SMTP。腾讯云于 2026-03-02 调整新开通个人账号的 SMTP 权限，参见[公告说明](https://cloud.tencent.com/document/product/1288/65749)。

1. 开通邮件推送，验证发信域名并创建发信地址，完成控制台要求的 DNS 配置。
2. 在该发信地址所属地域创建并审核通过两份邮件模板。变量采用 `{{变量名}}`，参见[腾讯云模板数据结构](https://intl.cloud.tencent.com/zh/document/api/1084/39418)。可以使用以下纯文本模板：

验证码模板：

```text
您正在为 CustodySim 账号绑定安全邮箱。
验证码：{{code}}，{{minutes}} 分钟内有效，请勿转发或告知他人。
此验证码仅用于确认邮箱地址，不能用于登录或关闭双重验证。
如非本人操作，请忽略本邮件。
```

通知模板：

```text
CustodySim 账号安全通知
事件：{{event}}
时间（UTC）：{{time}}
如非本人操作，请立即联系系统管理员并保护您的账号。
```

3. 创建仅允许 SES `SendEmail` 的 CAM API 凭据，写入服务端 `.env.local`：

```dotenv
TENCENT_SES_SECRET_ID=
TENCENT_SES_SECRET_KEY=
TENCENT_SES_REGION=
TENCENT_SES_FROM=
TENCENT_SES_CODE_TEMPLATE_ID=
TENCENT_SES_NOTICE_TEMPLATE_ID=
```

地域必须与发信地址和模板一致，例如 `ap-guangzhou`；发信地址填写纯邮箱地址。以上均不使用 `NEXT_PUBLIC_` 前缀。保持 `MFA_ENCRYPTION_KEY` 稳定，否则已有验证器、加密邮箱及待发送通知无法解密。

4. 运行 `pnpm db:push`，重启应用，管理员打开“安全邮件”（`/security-mail`），查看配置状态并开启“允许绑定安全邮箱”。页面不回显 SecretId、SecretKey 或完整发信邮箱。配置齐全仅代表本地格式检查通过，实际投递需要真实账号、审核通过的模板及可用额度。
5. 用户从账号菜单进入“安全设置”（`/security`），输入邮箱和当前密码；已开启 MFA 时还需新一组验证器代码或未使用的恢复码。邮件验证码确认后退出所有会话，重新登录即可使用。

## 安全行为

- 验证码为随机 6 位数字，5 分钟有效，数据库仅保存绑定挑战 ID 的 HMAC；邮箱和通知内容使用现有 MFA 加密机制保存。
- 每账号及收件邮箱每小时最多 5 次发送尝试、60 秒间隔；每 IP 每小时最多 20 次。错误凭据和发送失败也占用额度。每个挑战最多验证 5 次，并有账号/IP 验证尝试总量限制；全部由数据库加锁计数，多进程共享。
- 发送在事务提交后执行。发送失败的验证码不可确认；重发使原挑战失效，不自动重发验证码。
- 确认绑定会原子消费挑战、替换已验证邮箱、提升账号会话版本、撤销受信任设备和待验证登录挑战，并写入审计；换绑时通知旧邮箱和新邮箱。
- 邮箱验证码不能传到登录 MFA 接口作为有效因子。TOTP 记录已使用时间步，MFA 登录挑战有随机 ID、到期时间、最多 5 次尝试和一次性消费；恢复码与受信任设备创建在同一事务中处理。
- 启用 MFA 时用于确认的那组 TOTP 也会消费，请等待下一组代码再登录；启用和关闭 MFA 均撤销其他会话与受信任设备，并通知已绑定邮箱。
- 安全通知随业务事务写入加密发件队列，每分钟扫描，最多尝试 5 次。页面显示等待和重试耗尽数量；API 接受不等于收件箱送达，实际投递查看腾讯云记录。进程在发送后、标记成功前崩溃可能产生重复通知。
- 过期验证挑战与发送限流记录约一天后清理，安全通知队列保留 14 天。关闭邮箱绑定只阻止新绑定/确认，不关闭已绑定邮箱的安全通知。

## 验证

`pnpm test` 包含腾讯云 SDK 调用契约及脱敏测试；`pnpm test:e2e:business` 在独立 `custodysim_e2e` 验证并发消费、换绑撤销、限流、失效、错误码耗尽、提供方失败及 MFA 防重放。测试用受控邮件替身，不向真实邮箱发信。
