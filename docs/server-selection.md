# App 服务器设置

## 使用者

登录页空闲时提供「服务器设置」；恢复登录、提交登录及验证期间隐藏入口。登录后从「我的 → 关于应用 → 服务器设置」进入，首页不展示入口或地址。

1. 填写管理员提供的公网 HTTPS 根地址，例如 `https://example.com`，不要附加 `/login`、`/api`、账号或密码。
2. 点「检测连接」。检测只读取兼容性信息，不发送当前登录凭据。证书、网络、协议不兼容或旧服务端没有检测接口时会显示失败，原服务器不变。
3. 确认页面说明后点「确认切换并重新登录」。只检测、关闭弹层或输入新地址，不会自动切换。
4. 用新服务器的账号重新登录。后台位置上报会关闭，需要时再到「我的 → 位置上报」开启。

切换会清除本机旧登录凭据及尚未上传的位置；不会删除服务端已有记录。草稿按服务器和账号分别保留，返回相同服务器并用相同账号登录时可以继续读取。切回以前的服务器也需重新登录，不恢复旧令牌或旧上传队列。

首版不提供同时登录多个服务器、忽略证书错误、自定义 API 子路径或单独填写聊天服务器。内网/HTTP 联调继续用开发构建配置，不通过此输入框添加。

## 服务端部署要求

新增匿名 `GET /api/mobile/server-info`，返回：

```json
{
  "success": true,
  "data": {
    "product": "CustodySim",
    "version": "1.5.2-test",
    "nativeProtocol": { "min": 1, "max": 1 },
    "realtimePath": "/socket.io/"
  }
}
```

响应不访问数据库，不返回人员、凭据或私有配置，禁止缓存。原生协议 1 须位于支持区间。版本号供展示，不以版本字符串做兼容判定。此接口必须先随新版服务端部署；旧服务端的 404 不会被当成兼容成功。

聊天自动使用相同来源的 WSS，仍需 Nginx 的 `/socket.io/` 反代。检测成功只确认 HTTPS 与发现协议，并不代表数据库、账号登录或聊天会话已全部验收。产品标识也不是服务器所有权证明，使用者仍需确认来源可信。

## 开发实现与切换边界

- `ServerEndpoint` 保存不可变 HTTP/WSS 地址；输入规范化后仅接受 HTTPS 域名根地址。探测、业务 HTTP 和 WebSocket 均不自动跟随重定向，不放宽 TLS 校验。
- `ServerSettings` 首次绑定已有编译期默认地址，保留升级前会话；用户选择的地址保存在应用私有 SharedPreferences，后续启动优先使用。
- 每次实际切换生成新的本地会话命名空间，隔离 TokenStore、定位状态与队列。旧 TokenStore 关闭后拒绝迟到的登录/刷新结果写入，清除操作仅影响自身命名空间。
- 旧容器停止 HTTP/聊天、禁用定位资格，清除待上传队列并禁止后续追加；取消并等待 WorkManager 取消操作落库，再保存服务器选择、替换依赖容器和页面状态。已到达旧服务端的请求无法由客户端撤回。
- 本地草稿使用服务器根地址、用户 ID 和表单标识作为键，退出旧容器前排空草稿写入；图片缓存按图片内容索引，不承载身份凭据。
- 切换不调用会注销该账号所有设备的服务端 logout，仅清除本机旧凭据。其他设备会话不受此操作影响。
- 公开 debug/release 无预置地址；本机 production 使用混淆的生产地址，development / benchmark 使用私有联调地址并隔离应用数据，见[构建变体](android-development.md)。运行时选择首版不支持局域网。

## 验证

自动检查包括地址规范化、拒绝不安全地址、每次切换命名空间唯一，以及服务端匿名响应契约。Android 真机隔离测试使用临时命名空间，检查令牌/可信设备不串用、旧响应不能重新写入以及旧定位队列关闭后不能追加。

2026-09-26：优化包、调试包和真机测试包构建成功，43 项 Android 单元测试、匿名接口契约测试、TypeScript 检查与新增代码 ESLint 通过，Lint 无 error。手机拒绝安装独立测试包，因此真机隔离测试未执行；已恢复覆盖安装最终 benchmark 优化包，保留用户数据。未部署服务端、未切换用户真实服务器。

真实跨服务器切换仍需两个已部署检测接口的 HTTPS 服务逐项验证：检测失败不切换、确认后重新登录、杀进程后地址保持、图文聊天、定位重新开启和返回原服务器读取对应草稿。不要以构建通过代替这些业务联调。
