# 使用指南：从登录到完成日常事项

适用于 1.5.2-test。本文供使用系统的人阅读，不需要安装开发工具或执行命令。请使用管理员提供的网址或 Android 安装包；账号、可见人员和可用功能由管理员分配。

## 先认识自己的入口

Web 是浏览器里的系统，App 是手机上的 Android 客户端。同一账号的数据由服务端保存，但两端菜单和功能范围不完全一样。管理、规则配置和安全设置优先在 Web 使用。

| 要做的事               | Android App                | 普通账号的 Web 入口    |
| ---------------------- | -------------------------- | ---------------------- |
| 点名打卡、申请补卡     | 底栏「点名」               | 「点名」               |
| 填写任务、看批阅结果   | 底栏「任务」               | 「服刑任务」           |
| 发起申请、看处理进度   | 底栏「申请系统」           | 「申诉与呈报」         |
| 聊天、发送图片         | 底栏「聊天」               | 「监室通信」           |
| 阅读通知               | 首页右上角公告图标         | 「监所公示」           |
| 填写与查看档案         | 「我的」中的档案入口       | 「在押档案」           |
| 更换头像               | 「我的」点击头像或个人资料 | 账号菜单「设置头像」   |
| 设置后台位置上传       | 「我的 → 位置上报」        | 网页不执行后台定位采集 |
| 修改密码、管理双重验证 | 使用 Web 安全设置          | 安全设置页面           |

监管人员和管理员的菜单名称不同，见[管理人员指南](staff-guide.md)。如果缺少某入口，先核对账号角色和管理员开放的权限。

## 第一次登录

如果管理员要求连接另一台服务器，先点登录页「服务器设置」，输入提供的 HTTPS 根地址并检测，确认后切换。登录后也可从「我的 → 关于应用 → 服务器设置」进入。切换需要重新登录，会清除尚未上传的位置并关闭后台上报；详细步骤见[服务器设置](server-selection.md)。

1. 打开提供的网址或 App，输入分配的用户名和密码。
2. 如果要求修改初始密码，先在 Web 完成改密，再用新密码登录 App；当前 App 没有改密页面。
3. 如果出现双重验证，输入验证器当前代码，或使用你事先保存的恢复码。共用设备不要选择信任设备。
4. 登录后核对姓名。不是自己的账号时退出，不要继续填写或提交。

密码连续输错可能触发等待时间，请按提示等候，不要反复点击。忘记密码、账号停用或遗失验证器且没有恢复码时，联系管理员。邮箱验证码不能代替登录双重验证。

## 每天建议按这个顺序查看

先看通知和今日点名，再检查任务截止时间，最后查看申请和档案的处理结果。聊天内容与正式任务、申请是不同记录：在聊天里说明情况，不等于已经提交了任务或申请。

## 点名与补卡

### 在开放时段打卡

1. 打开「点名」，查看今日汇总和打卡起止时间。
2. App 在汇总下面突出显示第一顺位打卡：有正在开放的时段时优先显示它，否则显示最近的即将开始时段。还未到时间时等待开放。
3. 根据需要设置「打卡 GPS」开关。App 会记住该选择，并用于后续打卡和补卡；它不控制后台位置上传。
4. 点「打卡」，按提示填写备注；要求必填时不能留空。需要时添加照片，核对后提交。
5. 等待成功提示，并确认记录变成已打卡、出现实际打卡时间。网络不稳时先刷新确认记录，不要只凭按钮被点过判断成功。

开启 GPS 需要手机系统定位服务和定位权限。App 获取 GPS 失败时不会自动改用 IP 定位；关闭 GPS 时使用网络地址推测的粗略地区，不能视为精确位置。网页 GPS 还需要安全的 HTTPS 访问环境。

### 已错过时段

在下方历史记录找到错过的打卡，若显示补卡入口，填写原因及所需凭证后提交。**补卡审核中不等于补卡已通过**；随后查看审核状态和意见。没有入口或无法提交时联系管理人员确认，不要修改手机时间尝试补打。

## 填写任务与查看批阅

1. 打开「任务」，App 按「待执行」「待批阅」「执行记录」组织内容。
2. 进入待执行任务，先读要求与截止时间，再按表单填写。不同任务字段可能不同，以当前表单为准。
3. 核对必填项、选项、日期和图片后提交。只有保存草稿或退出页面，不代表已提交。
4. 提交后到「待批阅」查看；处理完成后查阅结果和已填内容。
5. 如被退回，先读批阅意见，再按页面允许的操作修改、重新提交。已逾期或已取消的任务以页面可用操作为准。

不要用聊天消息替代任务表单。遇到“状态已变化”等提示，刷新记录后再决定下一步，避免按过时状态操作。

## 发起申请

1. App 打开「申请系统 → 发起申请」；Web 打开「申诉与呈报」。
2. 选择页面提供的申请类型，写清事由。需要起止时间的类型，使用日期/时间选择器填写；有附件要求时补齐材料。
3. 提交后回到申请列表确认记录出现，再查看后续审核状态和意见。

**发起申请不等于批准。** 请假或临时离监以最终批复的起止时间为准，不以自己填报的时间或中间审核结果为准。被退回时按意见补充材料；界面不能处理的情况联系审核人员。

## 档案填写、签名与导出

1. 从「我的 → 档案填写」进入，选择可用分卷；Web 从「在押档案」进入。
2. 阅读说明，逐项填写带必填标记的内容。长表单可以上下滚动，出生年月和刑期等字段用选择器填写。
3. 到「电子签名」选择规范签名或手写签名。规范签名按当前账户姓名生成；手写签名在签名区域绘制并确认。
4. 尚未准备好时点「保存草稿」。需要进入审核时，核对完整内容后点「提交会签」。
5. 到「档案查看」核对状态。公章在最终审批后处理，草稿里没有公章不代表显示故障。只读或归档记录不能随意修改。

查看页可生成身份牌和档案图片。生成图片用于查看或保存，**不会代替提交会签，也不会使草稿自动变为已批准**。Android 显示保存成功后，可到系统相册或「图片/CustodySim」查找。找不到时先查看页面结果和提示，参见[常见问题](faq.md)。

## 聊天与图片

- 打开「聊天」后选择可用会话。发起跨监室私聊可能需要填写理由并等待审批，可在「私聊申请」查看进度。
- 发送文字：输入内容后点发送。发送图片：点图片图标选图；说明可留空，也可填写，图和说明显示在同一条消息中。
- 点消息图片进入黑底全屏查看，使用返回操作退出。点消息区空白处可以收起键盘。
- 需要撤回时，在 App 长按自己可撤回的消息，确认撤回。当前撤回窗口为发送后 5 分钟，以实际入口和服务端结果为准；撤回不会消除对方已经看到或自行保存的内容。
- “已发送”和“已读”含义不同。没有已读标记，不一定是发送失败；先确认消息是否已出现在会话中。

聊天不是永久档案库。普通用户可读取近期 14 天消息，监管审计窗口为 28 天，服务端默认清理超过 28 天的数据；实际清理设置由维护人员管理。

## 通知、头像与外观

App 首页右上角进入通知，阅读内容后可按页面操作「确认已阅」，再检查已读状态。系统内通知与手机系统通知不同：手机没有弹出通知，并不说明系统内没有新内容。

更换头像时，选图后拖动、缩放裁剪，确认预览，再点保存才更新账号。取消裁剪或只停在预览不会保存。恢复默认也需要确认保存；另一端可能需要刷新后显示。

App「我的」提供外观和材质设置。设备性能或省电状态会影响效果；视觉效果改变不影响任务、申请和聊天数据。

## 后台位置上传怎么设置

在「我的 → 位置上报」控制开关和上传周期，可选范围由服务端决定。这个开关与「点名」里的打卡 GPS 开关独立，打开其中一个不会自动打开另一个。

开启后按系统提示授予所需定位权限。位置上传通知用于显示上传结果；5/10 分钟短周期还会使用常驻通知。首次打开应用且恢复账号、满足开关和权限条件时会尝试采集；长时间停留前台也会检查是否到期。

后台间隔是尝试周期，不是精确定时承诺。断网、省电、强制停止应用和厂商后台限制都可能造成延迟。首页的「等待上报」表示还有数据未传完，不能当成上传完成。不要为了看到成功提示反复切换开关；先检查系统定位、网络和权限。

## 不熟悉的状态是什么意思

| 状态                     | 你可以怎样理解                                 |
| ------------------------ | ---------------------------------------------- |
| 草稿                     | 已暂存，但未进入正式审核流程                   |
| 待批阅 / 待审批 / 会签中 | 已提交，等待相关人员处理，尚不是最终批准       |
| 已退回                   | 需要先看意见，按可用入口修改补充               |
| 已通过 / 已批准          | 该记录显示已获相应处理；逐级申请仍核对最终批复 |
| 已归档                   | 进入归档状态，通常按只读方式查看               |
| 已逾期 / 已错过          | 已超过任务或打卡时段，是否可补办看实际入口     |

遇到问题先看[常见问题](faq.md)。向管理人员求助时提供发生时间、页面、提示文字和必要截图，遮挡无关个人信息，不发送密码、验证码或恢复码。
