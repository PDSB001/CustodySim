## 源码确认并修复

- 登录失败保留账号和密码输入，避免 React 表单 action 完成后自动重置。登录与 MFA 同步防重复提交，跳转期间维持忙碌状态；补按钮与错误反馈的辅助识别信息。
- 首页审核队列数量未读取或读取失败时显示“审核数量暂不可用”，避免把未知数量当成“当前无待审事项”。
- 社区长标题、正文、评论和档案快照允许窄屏断行。发布、评论及删除期间锁定内部切换，错误保留草稿；评论发布后读取最新数量并定位末页。
- 图片处理状态反馈给外层，社区及档案在压缩完成前禁止提交，处理中禁止移除图片。档案按字段聚合处理状态，证件照等待压缩及读取全部结束。
- 档案表单和记录均加载后才开放编辑，失败有重试入口；数量尚未读取时使用“—”。保存、提交及随后刷新完成前禁用编辑，提供操作进度；切换档案隔离旧异步结果。
- 切回规范签名不再展示旧手写签名。文字、数字、下拉和多行字段补齐辅助识别标签。

全部可选文字、数字和日期字段（含身份字段）的自愿分享规则保持原样；照片、签名、公章仍不分享。
